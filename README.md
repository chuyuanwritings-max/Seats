# 排座位 · 试玩版

中文版《Is This Seat Taken?》式排座位小游戏：一家人的一年，你是新进门的媳妇，每次家庭聚会都由你来安排座位。

**在线玩**：https://chuyuanwritings-max.github.io/Seats/ （在仓库 Settings → Pages 打开后可用）

## 怎么玩

- 把门口的人拖到位子上，或者先点人、再点位子。
- 每个人都有规矩（辈分座次、会干什么活）和心思（想挨着谁、躲着谁）。满意就笑，不满意就皱眉。
- 所有人都满意时，右下角黄历牌变红，点它开席。
- 网址后面加 `?test` 可以看每关的解数自检。
