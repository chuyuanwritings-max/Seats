## 怎么玩

- 点一下人，看他的心思卡；把门口的人拖到位子上（拖到有人的位子 = 两人对调，拖回门口 = 先不坐）。
- 心思卡上的小方框会实时打勾。所有人都坐下后，右下角的本子亮起，按它确认。
- 必须人人满意才能按确认；有人不满意时按确认，本子会晃一下，不满意的人会嘟囔是哪里不对。
