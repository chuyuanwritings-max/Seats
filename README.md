# 请入席 · 排座位试玩版

中文版排座位小游戏：一家人的一年，你是新进门的媳妇，每次家庭聚会都由你来安排座位。结构学《Is This Seat Taken?》，题材、人物、画面都是我们自己的。

**在线玩（最新 2.2）**：https://chuyuanwritings-max.github.io/Seats/
旧版本：2.1 在 `/Seats/v21/`，2.0 在 `/Seats/v2/`，1.0 在 `/Seats/v1/`

## 怎么玩

- 点一下人，看他的心思卡；把门口的人拖到位子上（拖到有人的位子 = 两人对调，拖回门口 = 先不坐）。
- 心思卡上的小方框会实时打勾。所有人都坐下后，右下角的本子亮起，按它确认。
- 人人满意拿金星；有人不满意也能过，只拿灰星。
